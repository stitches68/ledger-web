# Paste into Base44 → New App → Build

Build a complete, polished, responsive web application named **LEDGER // BLACKSITE NETWORK**. It is a fictional underground private-military-contracting network and fleet-management game for the R.E.A.P.E.R. Divers Helldivers 2 community. The user wants the detailed interface of a clandestine arms dealer combined with a deep idle fleet simulator, **not a corporate dashboard**.

**IMPORTANT PRODUCT CONSTRAINTS**
- This is a NEW independent Base44 app. Do NOT modify, rehost, or attempt to replace the existing LEDGER Python Discord bot on Railway.
- Use Base44-managed authentication, entities, row-level permissions, backend functions, and scheduled workflows. Do not use localStorage or frontend state as the source of truth for wallets, purchases, inventory, rewards, or deployments.
- A Base44 user is NOT automatically authenticated as a Discord user. Add an optional "Link Discord account" workflow using secure server-side Discord OAuth2 with `identify` and strict state/CSRF validation. Do not claim Base44 has built-in Discord login. Never expose the Discord client secret, bot token or server key to the browser.
- The Discord bot's existing SQLite database is on a separate Railway service and is **not readable/writable by Base44**. Keep a distinctly labeled WEB WALLET. Site-earned Blacksite Credits are web-simulation credits until a staff-reviewed claim is reconciled. Do not silently award real Discord currency or pretend `/balance` synced. Provide a staff queue for manual redemption; only staff may mark claims paid.
- The HD2 Galactic Map uses **read-only, unofficial community war data**. Assets in this website simulate their own battles; they cannot affect the actual Helldivers war. Clearly label: "LIVE COMMUNITY DATA", "CACHED", or "FEED OFFLINE"; never mark mock planets as live. Cache server-side and follow external API rate limits.
- All credit mutations, catalog prices, RNG/loot quality, operation progress, bonus multipliers, cooldowns, purchases, and role checks must happen server-side. Users may edit ONLY their own customization fields. Require ownership verification on every operation; reject untrusted costs and client-supplied balance numbers. Persist transaction logs and dedupe payout attempts using idempotency keys. Provide admin audit views.
- This is fictional game equipment, not real products. Do not create checkout links for weapons or other regulated goods.

10. **BROKER TRANSMISSIONS** — original lore, random easter eggs and coded messages, antihero satirical black-market voice, hidden lore logs. Do not use copyrighted dialogue or copy Melchior/S.C.O.U.T. branding.
11. **ADMIN / CONTROL DESK** (admins only, hidden otherwise) — create/edit/remove contracts and catalog listings; moderation of pending redemption claims; adjust web wallet with reason + audit log; inspect anomalies; configure HD2 API feed status; export CSV; manage roles, invite links, featured announcements. ## Asset and gameplay depth
- Seed from the supplied CSV/JSON data: 34 original hull/squad models, 24 modules, 30 fictional weapons. Include Ghostknife, Wraith-7, Shrike, Basilisk, Nightglass, Hammerfall, Skyrend, Lifeline, Aurora, Quiet Mercy, Vaelora, Strigoi, Hollowstar, Judicator, Blackstar, Sanctuary Array, Pilgrim, Mastiff, Razorback, ANGEL Trauma Team, Ghost Team, and others.
- Supply a clear **class balance table**: fighters are fast and inexpensive; medical craft reduce losses and improve evacuation payout; carriers augment fighter earnings; cargo improves salvage and logistic rewards; battleships handle siege at higher running cost; stations yield stable but slower returns; tanks and ground mercs specialize on ground operations.
- Equipment rarities: Standard, Enhanced, Rare, Blacksite. Purchases roll quality ON SERVER, stored permanently. Avoid pay-to-win loops or uncapped growth. Caps: e.g. passive income multiplier maximum 1.75x, source of each bonus explained in a popover. Damage and wear reduce income and require repairs.
- Every 30 minutes, a server workflow calculates deployment ticks. Use deterministic idempotency key per `asset_id + tick_time`, so retries do not pay twice. Support processing missed ticks on return, capped to a safe time window. Friendly no-money-involved gameplay. Include battle reports and summary receipts.
- Contracts may require 1–25 accepted patrols, include bonus objectives that pay less than base, and can be repeatable. Keep progression per contractor, per contract, per cycle. Never multiply a single patrol result across every contract; require an explicitly active assignment.
